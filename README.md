# Python Learning Journey

A project-based journey for learning Python through **100 practical projects**, starting from the fundamentals and gradually moving toward real-world applications.

The goal is to learn Python by **building, practicing, and solving problems**, rather than relying only on theoretical study.

---

## About This Project

**Python Learning Journey** is a structured collection of 100 Python projects designed to build programming skills step by step.

The projects start with simple console programs and gradually introduce:

* Programming fundamentals
* Conditions and loops
* Lists and tuples
* Strings
* Functions
* Dictionaries and sets
* Files and exception handling
* Object-oriented programming
* Automation and command-line tools
* APIs and real-world applications

Each project focuses on practicing specific concepts through implementation.

---

## Why This Project?

Learning programming only through tutorials and theory is not enough.

This project was created to turn Python concepts into practical skills by following a simple approach:

```text
Learn → Practice → Build → Improve
```

Instead of trying to learn everything at once, the projects gradually increase in difficulty and complexity.

# Goal

The main goal of this repository is to complete **100 Python projects** and gradually develop practical programming skills.

By the end of the journey, the aim is to have hands-on experience with:

* Python fundamentals
* Problem solving
* Data structures
* Functions
* Error handling
* File operations
* Object-oriented programming
* Automation
* Command-line applications
* APIs
* Web scraping
* SQLite
* FastAPI
* Building practical Python applications

The focus is not simply on completing 100 projects, but on **learning from each project and improving through practice**.

# Progress Philosophy

A project is considered complete when it has been implemented, tested, and understood.

The checklist is used to track progress:

```text

```

The goal is to move through the projects consistently rather than rushing through them.
