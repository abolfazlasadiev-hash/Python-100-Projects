# Sum Two Numbers

## Description

A simple Python program that asks the user for two numbers and calculates their sum.

## Concepts Practiced

* `input()`
* Variables
* `float()`
* Arithmetic operators
* `print()`

## How to Run

```bash
python SumTwoNumbers.py
```

## Example

### Input

```text
Enter the first number: 10
Enter the second number: 25
```

### Output

```text
Sum: 35.0
```

## Goal

Practice receiving multiple values from the user, converting input into numbers, performing arithmetic operations, and displaying the result.
