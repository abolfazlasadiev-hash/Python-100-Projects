# Personal Greeting

## Description

A simple Python program that asks the user for their name and displays a personalized greeting.

## Concepts Practiced

* `input()`
* `print()`
* Variables
* String formatting
* User input

## How to Run

```bash
python PersonalGreeting.py
```

## Example

### Input

```text
Abolfazl
```

### Output

```text
Hello, Abolfazl!
```

## Goal

Practice receiving input from the user, storing it in a variable, and using it to create a personalized message.
