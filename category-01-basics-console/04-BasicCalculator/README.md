# Basic Calculator

## Description

A simple Python calculator that asks the user for two numbers and an arithmetic operation, then displays the result.

## Concepts Practiced

* `input()`
* Variables
* `float()`
* Arithmetic operators
* `if` / `elif` / `else`
* User input
* Basic error handling

## Supported Operations

* Addition (`+`)
* Subtraction (`-`)
* Multiplication (`*`)
* Division (`/`)

## How to Run

```bash
python BasicCalculator.py
```

## Example

### Input

```text
Enter the first number: 10
Enter an operation (+, -, *, /): *
Enter the second number: 5
```

### Output

```text
Result: 50.0
```

## Goal

Practice taking multiple inputs, selecting an operation based on user input, performing arithmetic calculations, and displaying the result.
