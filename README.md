# Python Learning Journey — 100 Projects

A structured, hands-on journey to learn **Python programming** by building 100 practical projects, starting with basic console programs and progressing toward automation, CLI tools, APIs, databases, and real-world applications.

The goal is simple:

> **Learn Python by building, practicing, and solving problems.**

This repository contains **100 projects organized into 10 progressive categories**, with each category introducing new Python concepts while reinforcing previously learned skills.

---

#  Main Goal

Build a strong practical foundation in Python through continuous project-based learning.

This journey covers:

* Python fundamentals
* Variables and data types
* Input and output
* Conditions
* Loops
* Lists and tuples
* Strings
* Functions
* Functional programming
* Dictionaries and sets
* File handling
* Exceptions
* JSON and CSV
* Object-oriented programming
* Automation
* Command-line applications
* APIs
* Web scraping
* SQLite
* FastAPI
* Real-world Python applications

By the end of the journey, you should be able to design, build, debug, and improve practical Python applications.

# Recommended Workflow

For every project, follow the same process.

### 1. Understand

Read the project's `README.md` and understand the requirements.

### 2. Plan

Break the problem into smaller steps before coding.

### 3. Build

Write the Python program and apply the concepts being studied.

### 4. Test

Try normal inputs, edge cases, and invalid inputs.

### 5. Refactor

Improve readability, organization, and error handling.

### 6. Document

Record what you learned in the project's README.

### 7. Commit

Save your progress with Git.

```bash
git status
git add .
git commit -m "feat: complete project"
git push
```

#  Project Philosophy

The purpose of this repository is not simply to complete 100 exercises.

The purpose is to develop **problem-solving ability through repeated implementation**.

Each project should encourage you to:

* Understand the problem
* Break it into smaller pieces
* Write the solution
* Test your assumptions
* Handle errors
* Refactor your code
* Document your work
* Commit your progress

As the projects become more complex, you should gradually move from:

```text
Writing small scripts
       ↓
Writing reusable functions
       ↓
Managing structured data
       ↓
Working with files
       ↓
Designing classes
       ↓
Automating tasks
       ↓
Building APIs
       ↓
Working with databases
       ↓
Building complete applications
```
