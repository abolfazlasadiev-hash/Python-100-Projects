# Category 01 — Basics & Console

## About

This category introduces the fundamental concepts of Python programming through small console-based projects.

The goal is to build a strong foundation before moving on to conditions, loops, data structures, functions, and larger projects.

## Learning Goals

By completing these projects, you will practice:

* Writing and running Python programs
* Using `print()` and `input()`
* Working with variables
* Converting data types
* Performing arithmetic operations
* Using basic operators
* Writing simple conditions
* Handling user input
* Solving simple programming problems

## Learning Path

The projects are designed to gradually increase in difficulty.

```text
01 → 02 → 03 → 04 → 05
                    ↓
10 ← 09 ← 08 ← 07 ← 06
```

Start with simple console output and user input, then gradually combine these concepts to solve more practical problems.
